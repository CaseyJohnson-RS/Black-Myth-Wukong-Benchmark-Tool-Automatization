# WukongBench

Консольный инструмент на C# для автоматического запуска **Black Myth: Wukong Benchmark Tool** (Steam): два прохода (CPU-тест и GPU-тест), сбор результатов и отчёт.

## Требования

- Windows 10/11 x64
- Установленный через Steam Black Myth: Wukong Benchmark Tool, **хотя бы раз запущенный вручную** (утилита правит существующий конфиг, а не создаёт новый)
- Запущенный Steam

## Запуск

1. Скачайте `WukongBench.exe` из [Releases](ссылка).
2. Положите его в любую папку с правами на запись (не в `Program Files`): рядом будет создана папка `results`.
3. Запустите. Если Windows покажет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (exe не подписан).

Если бенчмарк установлен не в стандартную папку Steam, передайте путь аргументом:

    WukongBench.exe "D:\SteamLibrary\steamapps\common\Black Myth Wukong Benchmark Tool"

### Сборка из исходников

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download):

```
dotnet run
```

Если бенчмарк установлен не в стандартную папку Steam, передайте путь первым аргументом:

```
dotnet run -- "D:\SteamLibrary\steamapps\common\Black Myth Wukong Benchmark Tool"
```

Пока работает инструмент (~10–15 минут), **не трогайте мышь и клавиатуру**: инструмент сам нажимает кнопки в меню бенчмарка.

Результат выводится в консоль и сохраняется в `results/<дата_время>/`:
- `report.txt` — характеристики ПК, результаты и настройки обоих тестов;
- `cpu_raw.json`, `gpu_raw.json` — исходные файлы результатов бенчмарка.

## Как это работает

1. Делает резервную копию `b1\Saved\Config\Windows\GameUserSettings.ini`.
2. Для каждого теста
    1. Записывает настройки в конфиг
    2. Запускает бенчмарк
    3. Проходит меню
    4. Ждёт файл результата
    5. Закрывает процесс
3. Восстанавливает исходный конфиг (в том числе при ошибке; если инструмент был убит, конфиг восстановится при следующем запуске).
4. Разбирает результаты и строит отчёт.

### Как были найдены способы управления бенчмарком

**Результаты.** Через поиск по изменённым файлам после прогона найден журнал запусков: `%TEMP%\b1\BenchMarkHistory\Tool\<unix-время>` — JSON с итоговыми метриками (`FPSAvg`, `FPSMin`, `FPS95`, загрузка CPU/GPU), применёнными настройками и ~10 000 покадровых замеров (`Records`). 

**Настройки.** Хранятся в `GameUserSettings.ini` в двух представлениях: `UISettingData` (значения меню) и `[ScalabilityGroups]` (группы качества Unreal Engine, `sg.* = значение меню − 1`). Инструмент меняет только нужные ключи в обоих блоках, остальной файл не трогает. Значения взяты из конфигов, сохранённых самой игрой через меню, а не подобраны наугад: **некорректное значение роняет бенчмарк на старте**.

**Запуск теста.** Штатного способа запустить тест без меню нет. Проверено:
- параметры командной строки — поиск по строкам `b1-Win64-Shipping.exe` не нашёл ничего, кроме стандартных флагоф Unreal Engine;
- `StartLevelName` в конфиге — уровень грузится, но тест запускается конечным автоматом игры из меню;

Поэтому меню проходится эмуляцией ввода.

## Выбор настроек

Общее для обоих тестов: полноэкранное окно, VSync выкл, ограничение FPS выкл, генерация кадров выкл, размытие в движении выкл, трассировка лучей выкл.

### CPU-тест

| Настройка | Значение |
|---|---|
| Разрешение | 1280×720 |
| Масштаб рендеринга | 50% |
| Все параметры качества | минимум |

### GPU-тест

| Настройка | Значение |
|---|---|
| Разрешение | 1920×1080 |
| Масштаб рендеринга | 100% |
| Все параметры качества | максимум |
